# Personal Agent

## Why

我希望通过这个项目真正理解 Agent 的工作方式，而不是直接让 AI
生成一个完整的 Agent 系统。

这个项目同时会作为课程 Lab 的实现，但重点是逐步搭建一个自己能够理解、
控制和长期使用的个人助手。

## Current Goal

目前先实现一个最小 Agent：

- 能与模型交互
- 能调用少量工具
- 能访问本地个人资料
- 能记录 Agent 的运行过程

暂时不追求复杂框架、完整 UI 或大规模自动化。

## Long-term Goal

最终希望它能够：

- 管理和检索个人资料
- 使用 RAG、OCR、URL 提取等能力
- 保存长期 Memory 和用户纠正
- 处理邮件和个人事务
- 组合多个工具完成完整任务
- 逐渐成长为一个长期使用的个人助手

## Principles

- 先理解，再实现
- 优先简单实现
- 不提前设计暂时用不到的抽象
- Agent 的核心设计由自己决定
- AI 主要用于辅助编码、调试和审查
